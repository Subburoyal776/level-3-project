# Level 3 Frontend Development Project

A responsive internship landing page and interactive image gallery built with HTML, CSS, JavaScript, and Bootstrap 5.

## Files
- `index.html` — website structure and content
- `style.css` — responsive layout, theme, cards, animations, and lightbox styles
- `script.js` — mobile navigation, lightbox, keyboard controls, and slideshow

## Run locally
Open `index.html` in a browser, or use the Live Server extension in VS Code.

## Before publishing
1. Replace the demo email `careers@example.com` with a verified contact.
2. Replace sample program statements with confirmed details from the internship provider.
3. Make sure you are allowed to use the company name and logo if this is an official submission.
4. Images and fonts load from external services, so an internet connection is needed.

## Deploy to GitHub Pages
1. Create a public GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/(root)`, then click **Save**.
6. Wait for the published link to appear on the Pages settings screen.

This is a static site. GitHub Pages can host it without a backend.
